Local-first architecture

Use the cheapest reliable control path first.

Fatir avoids throwing every action at a cloud model. Fast deterministic paths handle what they can, local models route and reason when useful, and cloud escalation is reserved for work that genuinely benefits from it.

Four working modes

Control where the intelligence comes from.

Fatir can stay strictly local or use cloud reasoning when you explicitly want the extra capability.

Fast Path

Zero-model deterministic actions when a built-in tool can handle the work safely.

Local Router

Small Ollama model for lightweight intent and tool selection.

Local Deep

Use a stronger local model for more involved reasoning.

Cloud escalation

Optional stronger reasoning or visual/browser planning when configured.

Built with boundaries

Automation should still know when to ask.

Fatir keeps consequential actions approval-aware and separates credentials from normal model context instead of treating desktop control as unrestricted automation.

Secrets stay out of normal model context.

Credential values live in Linux Secret Service / keyring. Passwords, OTPs, API keys, recovery codes and payment data are not intentionally placed into prompts or logs.

Consequential actions remain gated.

Destructive, privileged, uninstall/remove/wipe and stored-credential actions require explicit approval. Headless browser operation is explicit-only.

FAQ

What Fatir is — and what it isn't.

What is Fatir?

Fatir is a resident local-first AI desktop assistant for Linux. It works beside your applications rather than acting like an IDE or another full-screen chat app.

Does Fatir run local AI models?

Yes. Fatir supports local-first routing through Ollama and can optionally escalate to configured cloud models for harder reasoning, visual understanding, or browser work.

Can Fatir control Linux desktop applications?

Yes. It prefers semantic AT-SPI controls, then falls back to window/keyboard control and finally X11 visual control where necessary.

Can Fatir work with my current Chrome tabs?

Yes. Its active/current browser mode is intended to attach to the Chrome session you are already using through Chrome DevTools MCP.

Is Fatir open source?

Yes. The project is published under the MIT License.

Is Fatir an IDE?

No. Fatir is a resident sidebar designed to work beside Chrome, Android Studio, Nemo, GIMP, VLC and other Linux applications.

Your Linux desktop already has the apps. Fatir gives them an operator.

Local-first where possible, model-assisted where useful, and verification-aware before calling the job done.
